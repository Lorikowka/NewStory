# Changelog

## 0.1.0-SNAPSHOT

- Создан начальный каркас независимого Java-ядра и Forge-модуля.
- Добавлены идентификаторы истории/экземпляра и контракт состояний Fiber.
- Исходная спецификация выделена в docs/source; добавлены архитектурные заметки и статус проверки.

- Структура переведена на корневой MDK src/; внутренние подпроекты перенесены в modules/.
- Добавлены runtime, строгий компилятор JSON, CLI и первый выполняемый headless-сценарий.

- Сюжетные реплики вынесены в центральную нижнюю плашку с текстурой головы.
- Добавлен каталог gameDir/storyengine для ассетов и внешних JSON-сценариев.
- Сведены спецификации в единый план; начат Kotlin DSL: независимый API для StoryNPC и последовательного графа say/wait, на нём построено встроенное chatdemo.
- Добавлен Kotlin scripting host для локальных `.se.kts`, CLI и пример `chapter_01.se.kts`; метаданные StoryNPC передаются через типизированную реплику в Forge-пакет.
- Подготовлены игровая загрузка локальных `.se.kts`, команды запуска и Forge Jar-in-Jar для Kotlin host; добавлена проверка содержимого JAR.

- Добавлены фоновая /story reload с откатом всего каталога при ошибке, awaitEvent в Kotlin DSL и серверное событие engine:block_interact; добавлены регрессионные тесты и пример interaction.se.kts.

- Добавлены think/whisper, передача DialogueMode в протоколе v3 и пример двух персонажей.

- /story validate local:id теперь проверяет текущий файл в фоне без активации и показывает источник; добавлены проверки ошибок и недопустимых путей.

- Добавлены явные PortraitMode CUSTOM_TEXTURE/NONE/FALLBACK, отсутствие отступа при NONE и narrative-протокол v4; прежний конструктор StoryNPC сохранён.

- Исправлены namespaced ID команд start/validate и загрузка Kotlin-библиотек в Forge development runtime; добавлен LRU-кэш PNG-портретов и проверки освобождения ресурсов.
