# Архитектура

Целевая цепочка: Story Pack → compiler → immutable definition → runtime → platform contract ← Forge.

Текущая структура описана в ADR-0002: Forge-код расположен в корневом src/, engine-core, engine-compiler и tools-validator — в modules/. Для проверки без Minecraft есть самостоятельная Gradle-сборка modules/.

Ядро исполняет immutable граф без JSON и Minecraft API. Runtime принадлежит создавшему его потоку; только publish допускает внешние потоки. Каждое событие адресовано instanceId. События до регистрации ожидания не сохраняются для будущих ожиданий. Тики строго возрастают; route выполняется до execute. Лимиты шагов ограничивают busy-loop даже при программном обходе компилятора. Терминальные экземпляры хранятся до явного forget; максимальное число ограничено.

Компилятор допускает JSON-поднабор из примера samples, проверяет ссылки и запрещает циклы без await/delay. Platform effect получает idempotency key, но атомарность с внешним миром и exactly-once не гарантируются. Постоянных сохранений пока нет.

Forge содержит только точку регистрации; интеграция runtime с сервером — следующий этап. Клиентские классы в точке входа отсутствуют.
