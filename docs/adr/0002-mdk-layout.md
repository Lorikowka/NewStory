# ADR-0002: привычная структура MDK

По запросу владельца мод расположен в корневом src/main/java и src/main/resources. Корневой build.gradle основан на предоставленном MDK Forge 1.20.1-47.4.28; wrapper взят непосредственно из этого ZIP. Версия ForgeGradle фиксирована на 6.0.54 вместо диапазона MDK.

Независимые части сохранены как подпроекты в modules/. Команды runClient, runServer и build работают из корня без прежнего -PwithForge. Отдельный запуск -p modules позволяет проверять headless-часть без настройки Minecraft. Ядро и компилятор упаковываются в JAR мода; Gson предоставляет Minecraft, копия библиотеки в JAR не включается.

Этот ADR заменяет организацию bootstrap из ADR-0001. Исходный ZIP и справочные файлы MDK хранятся в docs/source. Пример ExampleMod не переносился. AGENTS.md оставлен неизменным по исходному указанию пользователя.
